# promotion_agent

국내영업본부 차량대리점팀 강준영 선임_프로모션 효과 시뮬레이션 에이전트

## 개요

세방전지 차량대리점팀의 월 마감 실적 워크북(엑셀)을 업로드하면, 대리점별 DC(할인)
지원금액과 프로모션(볼륨/연동형 등) 지원금액을 자동으로 계산하고, 그 효과를 교차 분석해
카드·차트 중심의 대시보드로 보여주는 Streamlit 애플리케이션입니다.

담당자가 매달 엑셀을 열어 수작업으로 계산·취합하던 과정을, 워크북 하나 업로드로 대체하고
"이번 달 프로모션이 실제로 매출·이익에 도움이 됐는지", "어느 대리점이 문턱값에 가까운지"
같은 질문에 바로 답할 수 있게 하는 것이 목표입니다.

## 주요 기능

- **워크북 업로드 → 자동 분석**: "DC율"·"프로모션 기준"·"DATA" 3개 시트로 구성된 월 마감
  워크북을 올리면 분석이 끝나는 대로 결과 대시보드로 자동 이동합니다(진행 상태 표시 포함).
- **DC + 프로모션 지원금액 자동 계산**: 대리점별 매출DC·성장DC와, 산식유형(품목별고정단가
  /구간별단가-절대수량/연동형/무상증정)별 프로모션 지원금액을 분리 계산합니다. 프로모션
  조건이 매달 바뀌어도 "프로모션 기준" 시트 값만 바꾸면 코드 수정 없이 반영됩니다.
- **분석 결과 대시보드**: 핵심 지표(매출·지원금액·영업이익율) 카드, 대리점별 지원금액
  순위, 프로모션 효과 평가(해당/미해당 비교), 문턱값 근접도(다음 구간까지 남은 대리점 검색
  가능), 영업이익율×매출증감율 산점도, 프로모션 장단점 분석 등을 제공합니다.
- **이력 조회**: 분석 결과를 DuckDB에 기준연월 단위로 저장해, 이후 재업로드 없이 과거
  기준연월을 다시 불러보거나 두 기준연월을 비교할 수 있습니다.

## 기술 스택

- **Streamlit** — 화면(업로드/분석 결과/이력 조회 다중 페이지)
- **pandas / openpyxl** — 엑셀 파싱·집계
- **DuckDB** — 기준연월별 분석 결과 저장(임베디드, 별도 서버 불필요)
- **pytest** — 계산 로직·화면 흐름 테스트

## 폴더 구조

```
app/
  streamlit_app.py     # 앱 진입점(페이지 내비게이션)
  workbook_ingest.py   # 워크북 파싱 + DC·프로모션 지원금액 계산(핵심 로직)
  dashboard.py          # 분석 결과 대시보드 카드·차트 HTML
  ui_common.py          # 공통 렌더링(디자인 시스템 CSS, 표, 이력 조회 등)
  views/                # 페이지별 스크립트(업로드/분석 결과/이력 조회)
  db.py                 # DuckDB 스키마·저장/조회
  tests/                # pytest 테스트
  scripts/              # 더미 워크북 생성 등 보조 스크립트
.docs/                  # 요구사항·설계 변경 이력(번호순)
design.md               # 세방그룹 CI 기반 디자인 시스템 정의
업로드 실적(8월)_더미.xlsx  # 실데이터를 가명화한 더미 워크북(제출·데모용)
```

## 실행 방법

```bash
python -m venv .venv
source .venv/Scripts/activate    # Windows: .venv\Scripts\activate
pip install -r app/requirements.txt

streamlit run app/streamlit_app.py
```

앱이 열리면 "실적 업로드" 페이지에서 `업로드 실적(8월)_더미.xlsx`(또는 같은 형식의 워크북)를
올려 바로 결과를 확인할 수 있습니다.

## 테스트

```bash
pytest
```
