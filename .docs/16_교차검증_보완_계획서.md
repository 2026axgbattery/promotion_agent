# 16. 프로모션 효과 교차검증 보완 계획서

## 배경/동기
사용자가 "이 프로모션이 효과가 있었는지, 차기엔 어떤 프로모션이 적절한지"를 판단할 교차검증 방법에 대해 의견을 물었고, 그 방향으로 진행해도 좋다는 확인을 받았다. 지난 답변에서 제안한 4가지 중 데이터가 이미 있어 바로 구현 가능한 것부터 진행한다.

## 범위 (우선순위 순)
1. **문턱값 근접 분포 분석**: 무상증정형(예: 10+1) 규칙이 계산됐을 때, 대리점×제품별 판매수량이 다음 문턱값까지 얼마나 남았는지(0=정확히 도달, 1~2대 부족, 3대 이상 부족) 분포를 보여준다. "프로모션이 추가 구매를 실제로 유도했는지" 직접 보여주는 지표다.
2. **영업이익율 × 매출증감율 산점도**: 대리점을 점으로 찍고 프로모션 해당/미해당을 색으로 구분해, "매출은 늘었지만 이익률은 깎인" 트레이드오프 패턴을 시각적으로 보여준다.
3. **대리점 그룹별(영업이익율 구간) 효과 비교**: 우수(15%+)/보통(0~15%)/저조(0% 미만) 그룹별로 대리점 수·평균 영업이익율·평균 매출증감율·평균 총지원금액을 비교한다(PRD 6.7절, 기존에 미구현).
4. (이번엔 보류) **같은 대리점의 전월 대비 전후 비교**: 여러 달치 데이터가 쌓여야 의미가 있어 이번엔 구현하지 않고, 데이터가 쌓이면 기간비교 기능을 확장하는 방향으로 남겨둔다.

## 방법
- 1번은 `app/workbook_ingest.py`의 프로모션 규칙 계산 결과(대리점×제품 판매수량, 문턱값 n)를 재사용해 `IngestResult.threshold_proximity` DataFrame으로 추가한다.
- 2·3번은 이미 계산된 `sales_like`만으로 만들 수 있는 순수 표시 기능이라 `app/ui_common.py`에 추가하고 분석 결과 페이지에 새 섹션으로 넣는다. 산점도는 Altair(Streamlit 내장)를 쓴다.

## 완료 기준

- `pytest` 전체 통과.
