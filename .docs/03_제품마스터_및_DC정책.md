## 1. 제품 타입 정정 사항

기존 PRD(및 이전 버전 목업)는 "제품군"을 `GB / AGM / 대형제품` 3종이 서로 겹치지 않는 분류로 가정했으나, 실제 제품 마스터를 보면 이는 **두 개의 서로 다른 축**이다.

- **타입(제품군)**: `GB` / `AGM` / `PT` 3종. (`PT`는 기존 PRD 10장에서 "GB/AGM/대형제품 외 추가 제품군이 존재하나 현재 프로모션 대상에는 해당하지 않는다"고 확인했던 바로 그 제품군으로 추정된다.)
- **대형제품 여부**: 타입과 무관하게 **용량(Ah) ≥ 100**이면 대형제품으로 간주하는 파생 속성이다. 예: `AGM 105L`(용량 105)·`PT 200`(용량 200)도 이 기준으로는 대형제품에 해당하지만, 지금까지 확인된 프로모션의 "대형제품" 대상 목록(8월 프로모션 참고)에는 GB 품목만 등장하고 AGM·PT는 포함되지 않았다. 즉 **"대형제품"이 프로모션 대상제품군으로 쓰일 때는 반드시 실제 대상제품코드 목록과 대조해야 하며, 용량 기준만으로 자동 판정하면 안 된다.** (`02_PRD.md` 10장 미해결 질문에 반영)

## 3. 대리점 DC 정책 (참고자료 — 시스템이 재계산하지 않음)

`02_PRD.md`의 "데이터 입력 전제"에 따라 담당자가 업로드하는 실적 파일에는 DC율이 이미 계산되어 포함되어 있으므로, 시스템은 아래 정책을 직접 계산에 사용하지 않는다. 다만 "편차 원인 구분" 화면에서 **대리점 간 DC율 차이가 왜 발생하는지**를 설명할 때 참고 근거로 인용할 수 있다.

### 3.1 매출 DC (기본, 매출 규모 구간별)
| 매출 규모 구간 | DC율 |
|---|---|
| 3억 미만 | 1.00% |
| 10억 미만 | 5.00% |
| 100억 미만 | 6.50% |
| 140억 미만 | 7.50% |
| 200억 미만 | 8.50% |
| 200억 이상 | 10.00% |

- 기존 PRD/목업이 가정했던 "대리점등급(A/B)별 고정 DC율"은 실제 정책과 다르다. 실제로는 **대리점의 매출 규모 구간**에 따라 결정된다.
- **확인 완료**: 판정 기준 시점은 **전년도 연매출**이다.
- 원본 표는 큰 구간부터 나열되어 있으나(200억이상→3억미만), 이해를 돕기 위해 위 표는 오름차순으로 재정렬했다.

### 3.2 성장 DC (추가 가산, 조건부)
| 조건 | 추가 DC |
|---|---|
| 월 전년대비 110% 초과 달성 | +1% |
| 전년대비 누계 110% 초과 달성 | +2% |
| 전년대비 누계 115% 초과 달성 | +3% |

- **확인 완료**: 세 조건 중 둘 이상을 동시에 충족해도 합산되지 않고, **충족한 조건 중 가장 큰 DC율 하나만 단일 적용**된다. (예: 월 110% 초과와 누계 110% 초과를 동시에 충족하면 +2%만 적용되고 +1%와 합산되지 않는다.)

### 3.3 총 DC율 = 매출 DC + 성장 DC
최종 DC율은 두 구성요소의 합으로 본다. 예: 매출 DC 5%(10억 미만 구간) + 성장 DC 3%(전년대비 누계 115% 초과 달성) = **총 DC 8%**.

## 4. 확인 완료 사항 (추가)
- `PT` 타입 제품이 향후 프로모션 대상이 될 가능성: **낮지만 존재함**. 현재는 프로모션 대상이 아니지만, 향후 대상이 될 경우를 배제하지 않고 설계한다(예: PRODUCT_MASTER·PROMOTION_MASTER가 타입 값으로 `PT`도 그대로 받아들일 수 있어야 함).
