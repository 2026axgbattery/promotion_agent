## 워크북 관련 엣지 케이스 점검

| 상황 | 처리 방식 | 확인 |
|---|---|---|
| 필수 시트(백데이터/총괄표/프로모션/대형) 누락 | `ColumnNotFoundError` 발생, 어떤 시트가 없는지 메시지에 포함 | ✅ `test_missing_required_sheet_raises` |
| 시트 안 필수 컬럼 누락 | `ColumnNotFoundError` 발생 | ✅ `test_missing_required_column_raises` |
| 매출액 0인 행 | 영업이익율을 0이나 오류가 아니라 N/A(NaN)로 처리 | ✅ `test_zero_revenue_row_yields_nan_margin_not_error` |
| 같은 기준연월 재분석 | 기존 저장분 삭제 후 재삽입(덮어쓰기) | ✅ `test_reanalysis_overwrites` (Day 2) |
| 백데이터 시트의 `max_row` 오보고(서식이 시트 끝까지 적용됨) | 첫 빈 행에서 순회 중단 | ✅ Day 2에서 발견해 수정, 실제 파일로 회귀 테스트 |
| DB 스키마 변경 후 기존 DuckDB 파일 재사용 | 마이그레이션 미지원 — 파일을 지우고 재생성해야 함 | ⚠️ 알려진 한계(`app/db.py` 주석에 명시), 자동화되어 있지 않음 |

## 이번 MVP에서 다루지 않은 것 (의도적 보류)
- 특화제품(TW/TAXI/TILLER 등) DC 배분 — 제품유형 라벨 ↔ `product_master` 제품코드 매핑 미확정
- 원가율·전월매출·매출증감율 — 이 워크북에 없음, 별도 자료 수령 대기
- 대리점 등급·프로모션ID 기반 로직 — 실제로 존재하지 않는 개념이라 전부 삭제됨(`02_PRD.md` 10절)
- 최종 결과물 단계 기능(편차 원인 구분·효과성 평가·대리점 그룹별 조회·기준연월 이력 조회 UI·프로모션 간 비교 등) — `output/*.html` 목업에는 있으나 MVP 코드에는 없음

## 결론
MVP 완료 기준(정확성·저장) 충족. 확장성은 두 번째 실제 사례로 재검증이 필요하고, 속도는 측정하지 않았다(우선순위 낮음, 사용자 확인). 특화제품 DC·원가율/전월매출/매출증감율은 자료가 모일 때까지 의도적으로 비워둔 상태이며, 최종 결과물 단계 기능은 이번 MVP 범위가 아니다.
