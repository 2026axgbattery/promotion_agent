# 기술 스택 문서 작성 계획서

## 배경/동기
사용자가 제공한 과제 등록 정보(과제명·배포환경·라이브러리·DBMS·MVP·최종 결과물)를 근거로, Streamlit 기반 구현을 확정하는 기술 스택 문서가 필요하다. `02_PRD.md`의 기능 요구사항·데이터 모델(7절)과 대조해 각 구성요소(Streamlit/pandas/openpyxl/DuckDB)가 어떤 PRD 요구사항을 충족하는지 명시하고, `05_DBMS_도입_및_연월탐색_계획서.md`에서 "구현 단계에서 결정"으로 남겨둔 DBMS 종류를 DuckDB로 확정한다.

## 범위
- 작성물: `08_기술스택.md`
- 포함 항목: 배포 아키텍처(다이어그램), 계층별 기술 스택 매핑(PRD 근거절 포함), DuckDB 선정 이유, MVP/최종 결과물 범위와 PRD 5절 기능 목록 간 정합성 확인(문구 차이가 있으면 그대로 노출)
- 제외: 실제 코드 구현, 상세 스키마 DDL

## 방법
- 사용자가 제공한 과제표 문구를 그대로 인용하고, `02_PRD.md` 5절(기능 목록)·7절(데이터 모델)과 대조한다.
- 과제표의 "MVP"/"최종 결과물" 문구가 `02_PRD.md` 5절의 MVP/v2/이후단계 구분과 정확히 일치하지 않는 부분이 있으면 임의로 통일하지 않고 차이를 그대로 기록한다.
- Mermaid로 배포 아키텍처를 표현한다.

## 완료 기준
- `08_기술스택.md`가 생성되고, DuckDB가 DBMS로 확정되어 `05_DBMS_도입_및_연월탐색_계획서.md`·`02_PRD.md` 7절과 모순되지 않는다.
- MVP/최종 결과물 범위 차이가 있다면 문서에 명시적으로 드러난다.
