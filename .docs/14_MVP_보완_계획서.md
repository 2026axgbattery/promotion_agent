# 14. MVP 보완 계획서 — 총평·편차 원인 구분·이력 조회

## 배경/동기
`output/02_분석결과화면.html` 목업에 있던 기능 중 MVP에 아직 없는 것들을 추가한다. 사용자 확인 사항:
- "대리점 x 제품 단위 결과"는 제품(SKU) 그레인 상세표가 아니라, 기존 "대리점 단위 요약표"에 DC율을 매출DC%/성장DC%로 나누고 DC지원금액·프로모션지원금액을 각각 더 잘 보이게 하는 것을 의미한다(대리점 단위 유지).
- `dummy_실적워크북.xlsx`를 사용자가 직접 수정해 "제품표"와 "프로모션 기준"을 한 시트("제품표, 프로모션 기준")로 합쳤고, 프로모션 기준을 실제로 표(프로모션명·기간·프로모션 내용·적용 제품 코드/제품명)로 구조화했다 — 이전엔 줄글이라 파싱이 불가능했지만 이제 가능하다. 다만 이번 요청 범위에는 포함하지 않고, 시트 이름이 바뀌어 기존 "프로모션 기준" 정확 일치 검색이 깨진 것만 고친다(내용은 여전히 텍스트로 그대로 보여줌 — 구조화 파싱은 별도 작업으로 남긴다).

## 범위
1. **이번 달 프로모션 효과 평가(총평)**: 총지원금액 > 0인 대리점(해당)과 0인 대리점(미해당) 두 그룹으로 나눠 평균 영업이익율·평균 매출증감율을 비교하고 그 차이(gap)를 보여준다.
2. **대리점 단위 표 보완**: 매출DC%·성장DC% 컬럼을 추가해 DC 구성을 볼 수 있게 한다(DC지원금액·프로모션지원금액·총지원금액은 이미 있음).
3. **편차 원인 구분**: 대리점을 2개 이상 선택하면 DC 구성·지원금액 내역·영업이익율·매출증감율을 나란히 비교하고, 차이가 DC율 때문인지 지원금액(프로모션) 유무 때문인지 짧은 총평 문장을 보여준다.
4. **이력 조회**: DuckDB에 저장된 기준연월 목록을 카드로 보여주고, 하나를 선택하면 그 시점에 저장된 대리점 단위 결과를 다시 불러와 보여준다(재업로드 없이).
5. **프로모션 기준 시트 조회 방식 수정**: 정확한 시트명 일치 대신 이름에 "프로모션"과 "기준"이 포함된 시트를 찾도록 바꿔, 사용자가 시트를 합치거나 이름을 바꿔도 텍스트 안내가 계속 동작하게 한다.

## 완료 기준
- 워크북 업로드 후 총평·DC% 컬럼·편차 원인 구분 비교가 화면에 보인다.
- 이력 조회에서 과거 저장된 기준연월을 다시 조회할 수 있다.
- `pytest` 전체 통과.
